# 贪吃蛇 · 视觉与交互规范

目标：打开就能玩，一眼看懂，手机和电脑都顺手。风格是深色、简洁、带一点霓虹感的复古街机。

## 1. 配色

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面背景 | `--bg` | `#0f172a` |
| 棋盘底色 | `--board` | `#111827` |
| 棋盘网格线 | `--grid` | `rgba(255,255,255,0.04)` |
| 蛇身 | `--snake` | `#22c55e` |
| 蛇头 | `--snake-head` | `#4ade80` |
| 食物 | `--food` | `#f43f5e` |
| 主文字 | `--text` | `#e5e7eb` |
| 次要文字 | `--muted` | `#94a3b8` |
| 主按钮 | `--primary` | `#22c55e`（文字 `#052e16`） |
| 次按钮 | `--secondary` | `#1f2937`（边框 `#334155`） |
| 遮罩层 | `--overlay` | `rgba(15,23,42,0.85)` |

全部写成 CSS 变量放在 `:root`，不要在别处写死颜色。正文和背景的对比度不低于 4.5:1。

## 2. 字体

- 字体栈：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 分数数字：`font-variant-numeric: tabular-nums`，变化时宽度不跳。
- 字号：标题 28px，分数 20px，按钮 16px，提示文字 14px。

## 3. 布局

从上到下单列居中，最大宽度 480px：

1. **标题**「贪吃蛇」
2. **分数栏**：左边「得分 12」，右边「最高 48」
3. **棋盘**：正方形 canvas，20×20 格，圆角 12px，带一点外发光 `box-shadow: 0 0 24px rgba(34,197,94,0.15)`
4. **按钮栏**：开始/暂停（同一个按钮切换文字）、重开
5. **操作提示**：电脑上显示「方向键 / WASD 移动，空格暂停」，触屏设备显示「在棋盘上滑动控制方向」

间距统一用 8px 的倍数（8 / 16 / 24）。

## 4. 棋盘与元素

- 每格之间留 1px 空隙，蛇身方块圆角为格宽的 25%。
- 蛇头比蛇身亮一档，并画两个小眼睛朝向当前方向，方便看清走向。
- 食物是圆点，带 1.2 秒一次的轻微呼吸缩放（0.85 到 1）。
- canvas 按 `devicePixelRatio` 缩放，高清屏不糊。

## 5. 按钮

- 高度 44px（满足触屏最小点击区域），圆角 10px，左右内边距 20px。
- 主按钮「开始 / 暂停 / 继续」用 `--primary`，次按钮「重开」用 `--secondary`。
- 状态：hover 亮度 +10%，按下 `scale(0.97)`，键盘焦点显示 2px `--snake-head` 外框（`:focus-visible`）。
- 按钮文字随状态变化：未开始显示「开始」，进行中显示「暂停」，暂停中显示「继续」。

## 6. 游戏状态与遮罩

棋盘上盖一层半透明遮罩，居中显示文字和一个主按钮：

| 状态 | 遮罩内容 |
|---|---|
| 未开始 | 「按 空格 或点击开始」+「开始」按钮 |
| 暂停 | 「已暂停」+「继续」按钮 |
| 游戏结束 | 「游戏结束」、本局得分；如果破纪录，额外显示「🎉 新纪录！」+「再来一局」按钮 |
| 进行中 | 无遮罩 |

遮罩淡入淡出 150ms。

## 7. 交互

- **键盘**：方向键和 WASD 控制方向；空格切换开始/暂停；Enter 在结束时重开。禁止直接掉头（向右时按左无效）。游戏进行时阻止方向键滚动页面。
- **滑动**：在棋盘上滑动，位移超过 24px 才算有效，按位移大的轴判方向。棋盘设 `touch-action: none`，防止页面跟着滚动或下拉刷新。
- **失焦自动暂停**：切到别的标签页（`visibilitychange`）时自动暂停。
- **加速**：每吃一个食物间隔缩短一点，从 150ms 逐渐降到最快 60ms；分数栏旁可显示小字「速度 Lv.3」。
- **反馈**：吃到食物时分数数字轻跳一下（scale 1.2 回到 1，150ms）；撞墙或撞到自己时棋盘轻微抖动 200ms 后再出结束遮罩。
- 尊重 `prefers-reduced-motion`：开启时关闭抖动、呼吸和跳动动画。

## 8. 移动端适配

- `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">`
- 棋盘边长 `min(92vw, 60vh, 480px)`，横竖屏都能完整显示，不出现滚动条。
- 页面四周留安全区：`padding: env(safe-area-inset-*)`。
- 按钮栏在窄屏下两个按钮等宽铺满。
- 禁用双击缩放和长按选中文字（`user-select: none`）。

## 9. 无障碍

- 按钮用真正的 `<button>`，可用 Tab 键切换。
- 分数区域加 `aria-live="polite"`，游戏结束文字可被读屏读出。
- canvas 加 `aria-label="贪吃蛇游戏棋盘"`。
