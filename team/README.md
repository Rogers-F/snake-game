# 贪吃蛇

纯静态网页小游戏，不依赖构建工具或第三方库。用浏览器直接打开 `index.html` 即可游玩（`file://` 也可以）。

视觉和交互以同目录的 [DESIGN.md](./DESIGN.md) 为准。

## 打开方式

进入 `team` 目录，双击 `index.html`，或在终端执行：

```bash
open index.html
```

也可以把整个 `team` 目录放到任意静态服务器下访问。

## 操作

- 方向键或 `W` `A` `S` `D`：转向。不能直接掉头（例如向右时按左无效）。
- 空格：开始、暂停、继续。
- 底部「开始 / 暂停 / 继续」是同一个按钮，文字随状态变化；「重开」会立刻重新开一局。
- 游戏结束时按 Enter，或点击遮罩上的「再来一局」。
- 手机：在棋盘上滑动。位移要超过 24 像素才会转向，取位移更大的那个轴。
- 切到别的标签页会自动暂停。

## 规则

- 棋盘 20×20。吃到食物得 1 分，蛇身变长一格。
- 起始间隔 150ms，每吃一个食物缩短 5ms，最快 60ms。分数栏旁的「速度 Lv.N」随间隔变化，开局是 Lv.1，吃到 2 个时是 Lv.3。
- 撞墙或撞到自己即结束。结束前棋盘会轻抖一下（系统开启「减少动态效果」时不抖）。
- 最高分保存在本机 `localStorage`（键名 `snake-high-score`）。本局分数超过开局时的最高分，结束画面会显示「🎉 新纪录！」。

## 文件

| 文件 | 作用 |

| `index.html` | 页面结构 |

| `DESIGN.md` | 视觉与交互规范 |
