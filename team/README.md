# 贪吃蛇

纯静态网页小游戏，不依赖构建工具或第三方库。用浏览器直接打开 `index.html` 即可游玩（`file://` 也可以）。

视觉和交互以同目录的 [DESIGN.md](./DESIGN.md) 为准。

## 打开方式

进入 `team` 目录，双击 `index.html`，或在终端执行：

```bash
open index.html
```

也可以把整个 `team` 目录放到任意静态服务器下访问。

## 操作

- 方向键或 `W` `A` `S` `D`：转向。输入会排成最多 2 步的队列，所以很快地先按「上」再按「左」，两步都会生效。不能相对于队尾方向直接掉头（例如正在向右、队列里还没有转向时，按左无效；队列末尾是「上」时，再按「下」无效）。
- 空格：开始、暂停、继续。撞墙或撞到自己后的抖动期间，空格和 Enter 不会跳过结算。
- 底部「开始 / 暂停 / 继续」是同一个按钮，文字随状态变化；「重开」会立刻重新开一局。
- 游戏结束时按 Enter，或点击遮罩上的「再来一局」。
- 手机：在棋盘上滑动。位移要超过 24 像素才会转向，取位移更大的那个轴。
- 切到别的标签页会自动暂停。

## 规则

- 棋盘 20×20。吃到食物得 1 分，蛇身变长一格。
- 起始间隔 150ms，每吃一个食物缩短 5ms，最快 60ms。分数栏旁开局显示「速度 Lv.1」，吃到 2 个时是「速度 Lv.3」。吃下 18 个食物后间隔降到 60ms，不再加快，这时显示「速度 Lv.MAX」。
- 撞墙或撞到自己即结束。结束前棋盘会轻抖 200ms（系统开启「减少动态效果」时不抖），抖动结束才出现结算，这段时间按空格或 Enter 不会重新开始。
- 蛇占满 20×20 棋盘时通关，遮罩标题为「🏆 通关！蛇已经填满棋盘」。
- 最高分保存在本机 `localStorage`（键名 `snake-high-score`）。本局分数超过开局时的最高分，失败结算会显示「🎉 新纪录！」，通关结算会显示「新纪录」。
- 未开始和暂停的遮罩不显示本局得分；只有失败或通关结算才显示。
