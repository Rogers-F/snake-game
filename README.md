# 贪吃蛇

纯 HTML、CSS、JavaScript 写成的浏览器贪吃蛇。没有构建步骤，用浏览器打开 `index.html` 就能玩，也可以直接部署到 GitHub Pages。

## 运行

在仓库根目录用浏览器打开 `index.html`。

也可以起一个本地静态服务：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

### GitHub Pages

1. 打开仓库的 **Settings → Pages**。
2. **Build and deployment** 里，Source 选 **Deploy from a branch**。
3. Branch 选 `main`（或你要发布的分支），目录选 **/ (root)**，保存。
4. 发布完成后，打开 Pages 给出的地址。

`styles.css` 和 `game.js` 都是相对路径，放在用户站点根目录或项目站点（`https://<user>.github.io/<repo>/`）都可以。

## 怎么玩

蛇会自己往前爬。吃到果实就变长、加分，同时速度逐渐加快。撞到墙，或者咬到自己的身体，这一局就结束。

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 转向 | 方向键，或 `W` `A` `S` `D` | 在棋盘上滑动，或点屏幕上的方向键 |
| 开始 | `Enter`、空格，或直接按方向键 | 点「开始」，或滑动 / 点方向键 |
| 暂停 / 继续 | 空格或 `P` | 点「暂停」/「继续」 |
| 重开 | `R` | 点「重开」或「再来一局」 |

- 每吃一个果实得 **10** 分，蛇变长一节。
- 速度从每步约 168 毫秒开始，每吃一个果实缩短约 7 毫秒，最快约 56 毫秒一步。界面上的倍率会跟着升高。
- 不能直接掉头。快速连按两个转弯会先记住，再按顺序执行。
- 最高分写在本机浏览器的 `localStorage`（键名 `snake-high-score`）里，刷新页面还在。换浏览器或清站点数据后会重置。
- 切到别的标签页时，进行中的一局会自动暂停。
- 右上角可以开关音效。音效开关也会记住。

占满整个棋盘时，这一局算赢。

| 文件 | 作用 |
